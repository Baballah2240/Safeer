# Buses, seat maps and drivers

Section 05 / 0.6.0. This records company equipment and staff. It does not schedule trips, sell seats or collect payments.

1. Sign in and open your company. New companies' administrators already have fleet and driver access. For an existing company, the Super Admin or a role manager must add the permissions under Company roles, using a company-scoped role. Branch and station roles do not grant this access.
2. Open Buses & seat maps and choose Create seat layout. Enter a code and English and Arabic names. The editor starts with two seats, an aisle and two seats on each of ten rows.
3. Change Rows and Columns as needed. Type a label in each seat cell and clear a cell to make an aisle. Number seats renumbers the filled cells in order. Save with your current password. Labels must be unique, ignoring capital letters, and a map can hold 1 to 100 seats.
4. Add a bus with a code, registration and one layout revision. Both codes and registrations are unique within the company.
5. To change a seat map, choose New revision. The earlier revision stays exactly as it was, and existing buses keep it. Edit a bus to move it to the new revision. If someone else saved first, refresh and review before trying again.
6. Edit details changes only a layout's names and whether it is active. Retire every active bus on a layout before retiring the layout. An active bus cannot use an inactive layout.
7. Open Drivers to add an employee code, English and Arabic names, an optional phone and an optional linked staff member. A link creates no login and grants no access. Clear Active when a driver leaves; records are kept, not deleted.

Company audit records layout, bus and driver changes. Viewing drivers needs its own permission, because driver records hold contact details. Support access cannot include fleet or driver data in this section.

Future trips must snapshot the bus and seat-layout revision when Section 06 implements scheduling. Stop before Section 06 until the owner approves it.
