# Hosting Safeer on Render at safeer.mohbaba.online

`render.yaml` defines one Node web service and one Render PostgreSQL database. `scripts/production.mjs` starts it. On every start it applies migrations as the database owner, keeps the limited `safeer_app` runtime role, and serves the web app on `PORT`. The API stays on the service's loopback.

## First deploy

1. In Render choose **New > Blueprint** and pick the Safeer GitHub repository.
2. When asked, set `SAFEER_OWNER_LOGIN` to the email of the first owner account. `SAFEER_APP_DB_PASSWORD` is generated by Render, and `DATABASE_URL` comes from the database.
3. After the first deploy, open the service **Logs** once to read the owner's temporary password. Sign in at `/staff` and change it straight away.
4. In the service **Settings > Custom Domains**, add `safeer.mohbaba.online`. Then, at the DNS provider for mohbaba.online, add a `CNAME` record named `safeer` pointing to the `*.onrender.com` address Render shows. Render issues the HTTPS certificate.
5. Check `https://safeer.mohbaba.online/privacy` and `/api/v1/health`.

## Notes

- The site answers only on `SAFEER_PUBLIC_ORIGIN`. Requests that reach it through the `onrender.com` address get 403, except the health check.
- Cookies are `Secure`, and HSTS is sent. Sign-in throttling uses the client address that Render's proxy adds.
- Back up the database from the Render dashboard. Starter plans keep limited point-in-time recovery, so check yours.
- Migrations only move forward. Never edit an applied migration.
- Pushing to GitHub triggers a Render deploy only when auto-deploy is on. Check the deploy status in Render.

# Hosting on a Namecheap VPS (Ubuntu 24.04)

`deploy/setup-ubuntu.sh` installs Node 24, PostgreSQL 16, Nginx and a Let's Encrypt certificate, and runs Safeer under systemd as the unprivileged `safeer` user.

1. Buy a Namecheap VPS with **Ubuntu 24.04**. Note its IP address and root password.
2. In Namecheap **Domain List > mohbaba.online > Advanced DNS**, add an `A Record`: Host `safeer`, Value = the VPS IP. Remove any `CNAME` for `safeer`.
3. Sign in: `ssh root@<VPS IP>`, then run:

       git clone https://github.com/Baballah2240/Safeer.git /opt/safeer
       OWNER_EMAIL=you@example.com bash /opt/safeer/deploy/setup-ubuntu.sh

4. Read the temporary owner password: `journalctl -u safeer | grep "Temporary password"`. Sign in at `/staff` and change it.
5. To update later, run the same command again. Logs: `journalctl -u safeer -f`.

Secrets live in `/etc/safeer.env` (root only). Back up the database with `sudo -u postgres pg_dump safeer > safeer.sql`. A private repository needs a GitHub deploy key or token for the clone.
