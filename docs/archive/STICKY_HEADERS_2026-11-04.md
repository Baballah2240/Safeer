# Sticky liquid-glass headers - D43

The owner requested headers pinned to the top with an Apple-inspired liquid-glass finish. Staff, Driver, Booking/marketplace and preview now use position:sticky/top:0 at desktop and mobile widths. Layered warm reflections, 28px background blur, saturation, subtle brightness, thin highlights and a soft shadow retain the black/brown palette. This is a CSS interpretation, not an Apple rendering framework. Headers keep their responsive wrapping and existing page gutters; mobile navigation above the staff header scrolls away before that header reaches its sticky position.

The shared theme module observes the current header's actual height and sets root scroll padding so scrolled/focused content clears it. It disconnects the old size observer when rendering replaces a header and follows the replacement. ResizeObserver is optional, with a CSS offset fallback. Sticky positioning itself is CSS-only. Existing reduced-motion/transparency, unsupported-blur, forced-color and print fallbacks remain. There is no native package, backend, schema, account, permission or money-policy change.
