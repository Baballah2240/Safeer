# Mobile app handover to Codex - 2026-11-09

Covers D57, D58 and D60. The source is on `main` of `Baballah2240/Safeer` (commit c8ea7dc and later). The live site is https://safeer.mohbaba.online.

## Where to work

- Work from this repository's own clone, for example `C:\Users\Lenovo\source\Safeer`. Do not commit Safeer to the Stocrant repository; the copy at `stocrant/projects/Safeer` holds only uncommitted local files and runtime data.
- Pushing `main` redeploys the website within about a minute. The apps load the website, so web changes reach phones without a reinstall.

## Commands

    npm.cmd run mobile:build      # signed website apps + lint (needs the upload key)
    npm.cmd run mobile:save       # copies APKs to mobile/releases/, regenerates src/app-release.js
    npm.cmd run mobile:install    # USB install over the existing apps (keeps data)
    npm.cmd run mobile:build:usb  # debug development channel (127.0.0.1:4320 via adb reverse)
    npm.cmd run mobile:save:usb

## What changed

- **D57 website channel**: automatic reconnect when the network returns, Retry reloads the current page, WebView state is restored, static assets are revalidated with ETags (304) while pages stay no-store, and the drawers were redesigned.
- **D58 phone layout**: the app draws into the camera cutout and passes its height to the page as `--safe-top`. At 760px and below, the Staff/preview sidebar is an off-canvas modal panel (inert page behind it, closed by backdrop, Escape or Android Back). Staff and Driver sign-in share the `auth-card` layout with a show-password control; `loginFormState` locks only the submit button.
- **D60 downloads**: the app appends `SafeerApp/<versionCode> (<flavor>)` to its user agent. `src/app-release.js` (generated by `mobile:save`) drives the Update notice inside the app, the Get-the-app notice in Android browsers, and the Download item in the menus. The app opens only `https://github.com/Baballah2240/Safeer/releases/...` links, in the phone browser.

## Releasing a new app version

1. Bump `versionCode` and `versionName` in `mobile/android/app/build.gradle`.
2. Run `mobile:build`, then `mobile:save`. Commit the regenerated `src/app-release.js` with the source.
3. Create GitHub release `v<versionName>` and attach `Safeer-Driver-<v>.apk` and `Safeer-Booking-<v>.apk` from `mobile/releases/`. The names must match.
4. Push. Installed apps then show the Update notice.
